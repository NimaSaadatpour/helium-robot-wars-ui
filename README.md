## About the Project

**Helium Robot Wars** is an Android action game featuring robot combat and sci-fi gameplay.

My contribution focused on the game's **user interface and visual presentation** using **Unity** and **Adobe Photoshop**.

## My Contribution

- Unity UI implementation
- HUD and gameplay interface design
- Menu and control interface elements
- Mobile-friendly UI layout
- Visual asset preparation
- Photoshop-based UI design
- Interface refinement for the game experience
